# v0.9 — Security case files

The frontend sandbox presents two connected surfaces: the read-only `/showcase` guide and the operational `/` console. Both use the same paper, ink, red-accent, and semantic status tokens in `public/design-system.css`.

## Run it

```bash
npm start
```

Open `http://127.0.0.1:4317/showcase`. No model, Apple signing certificate, or GitHub account is required to explore the guide. The console's scripted demo also works without Ollama; the AI agent needs an installed local model.

## What is real, and what is illustrated

The six immutable cases explain sensitive-file denial, shell denial, one-use approval, traversal denial, recorded native sandbox-denial acceptance, and audit tamper detection. Every step is a reconstruction from documented behavior. The guide never calls local APIs, executes tools, grants approvals, reads files, or regenerates evidence.

The native case describes a separately compiled signed worker-source diagnostic from the historical v0.8 acceptance. It does not claim a fresh test or a byte-identical installed worker. The architecture explorer distinguishes the unsandboxed Node control plane from the narrow signed macOS worker. Evidence disclosures state each claim's limits.

## Interactions

- Select any case; use previous/next, restart, or direct step controls. Arrow keys and Home/End work within the step sequence.
- Copy a URL containing the selected case and step. Reload and browser history preserve valid case selection; invalid case identifiers show a helpful fallback.
- Select an architecture component to inspect its responsibility and limitation.
- Filter five evidence records, then expand the source and scope details. Evidence hash links reveal the relevant record.
- Open the local console to run actual requests, inspect activity, and review pending approvals.

The guide uses native links, buttons, and details disclosures. Content is inserted as text rather than HTML. Shared styles are served through one new exact-match route; existing CSP and API controls remain in force.
