02 / ARCHITECTURE

Different checks. Different boundaries.

Not every part of this prototype shares the same enforcement mechanism.

  1. 01

    Model or MCP client

    Proposes a tool call. Its request does not itself confer execution authority.

  2. 02

    Node guard and policy

    Checks selected routed calls against deterministic rules and an allowlist.

  3. 03

    Optional bounded review

    Eligible note writes can require a single-use operator decision before their guarded execution path resumes.

  4. 04

    Execution and authenticated audit

    Guarded operations and decisions are recorded in the local HMAC-linked audit system.

SEPARATE OS BOUNDARY

Signed macOS XPC worker
