    03 / Show your work

    Claims, with receipts.

    Read what was tested, how it was tested, and where the evidence stops.

    5 records
    E—01
    AUTOMATED REGRESSION TESTS

    Policy runs before the tool.

    Denied requests never reach the guarded execution callback.

    +

    What is checked

    Sensitive filenames, traversal, unknown tools, and shell requests are denied. Only eligible workspace reads reach trusted adapters.

    Evidence limit

    Applies to calls routed through this guard. It does not intercept arbitrary host activity or prove race-complete filesystem confinement.

    Read guard tests ↗
    E—02
    AUTOMATED REGRESSION TESTS

    One approval. One exact write.

    Immutable note content, one-use decisions, and a 90-second expiry.

    +

    What is checked

    A pending note creation resumes only after approval. Denial, expiry, and shutdown stop execution. Existing filenames cannot be overwritten.

    Evidence limit

    The local queue is held in memory. It provides no independent operator identity or approval durability across restarts.

    Read approval tests ↗
    E—03
    INTEGRITY & RECOVERY TESTS

    Changed history leaves a trace.

    Authenticated records, crash-recovery journaling, and checkpoint comparison.

    +

    What is checked

    Invalid event chains fail closed. An exact interrupted journal write can recover; unrelated corruption cannot. Previously anchored receipts enable historical comparison.

    Evidence limit

    Local keys remain accessible to the same OS user. HMAC integrity does not make logs immutable or protect future receipts from a compromised signing key.

    Read audit trust guide ↗
    E—04
    ON-DEVICE ACCEPTANCE · OCT 19, 2026

    The operating system says no.

    A signed worker-source diagnostic was denied host-file and loopback access.

    +

    Recorded result

    The diagnostic could write and fsync in its own container, but could not read a host-private file or reach a live loopback listener. Installed required-mode MCP tests also passed separately.

    Evidence limit

    The diagnostic is a separate build of worker source, not the byte-identical installed worker. Results are author-recorded local Mac acceptance, not a new test run from this page.

    Read native acceptance ↗
    E—05
    SYNTHETIC NATIVE ACCEPTANCE · OCT 19, 2026

    Uncertainty stays uncertain.

    Replay is refused; interrupted handoffs remain nonretryable.

    +

    Recorded result

    The pinned Keychain RSA suite rejected forged reviews and durable nonce replay after worker restart. Crash-before and crash-after reservation both remained UNCERTAIN.

    Evidence limit

    This is a fixed synthetic fixture, not crash-atomic real-document transfer. Neither a missing marker nor a matching marker proves success or rollback.
