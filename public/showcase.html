    DESIGN PRINCIPLES

    Security controls worth seeing.

    01 / POLICY

    Decide before acting.

    Tool calls go through a deterministic guard. Unsupported or risky actions fail closed before execution.

    02 / HUMAN

    Approve the exact thing.

    Eligible note writes pause for one-time review of the requested content. Approval does not grant arbitrary access.

    03 / KERNEL

    Move the boundary to the OS.

    The macOS required-mode worker is separately sandboxed and signed. The Node control plane is not sandboxed.
